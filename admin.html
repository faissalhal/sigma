Administration du site

Gérez les projets affichés sur le site et les prix de l'outil de chiffrage. Chaque enregistrement est publié directement sur le dépôt GitHub du site (mise à jour en 1 à 2 minutes).

Connexion

Comment obtenir un jeton ?
  1. Sur GitHub, connecté au compte propriétaire du dépôt, ouvrez Settings → Developer settings → Personal access tokens → Fine-grained tokens, puis Generate new token.
  2. Nom : « Admin site SIGMA ICC ». Expiration : selon votre choix (par exemple 1 an).
  3. Repository access : Only select repositories → faissalhal/sigma.
  4. Permissions → Repository permissions → Contents : Read and write. Rien d'autre.
  5. Générez, copiez le jeton et collez-le ici. Ne le partagez avec personne : il permet de modifier le site.
